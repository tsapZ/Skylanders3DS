# Findings 2026-11-11: the portal's commands (reply table experiments)

Giants 3DS at "Aim at the PORTAL OF POWER", Azahar with the portal patch, replies from a table
(SKYLANDERS_PORTAL_REPLIES). Every packet the game sends starts with `ff ff ff`; the rest is the console
portals' command set.

| Try | Table | What the game sent next |
|---|---|---|
| none | (silent) | `52 00` (R) three times 300 ms apart, disconnect, again |
| A | R -> `52 02 1b` (a USB Trap Team portal's answer) | accepted: `41 01` (A: activate), `43 ff ff ff` (C: the portal light white) four times, `41 01`, `43 ff ff ff` three times, `41 00` (A: deactivate) twice, disconnect, again |
| B | A, then also A -> `41 <flag> ff 77` (the USB portal's echo) | accepted: after `41 00` it activates again (`41 01`) and asks `53` (S: the status) three times, then disconnects. Unlike a USB portal, which sends its status by itself, the 3DS game asks for it |
| C | B, then also S -> `53 00 00 00 00 00 01` (no figure, counter 0, active; skylanders-portal's status layout) | **the game takes the portal**: the screen goes from "Aim at the PORTAL OF POWER" to "Place a toy on the PORTAL OF POWER", and the connection stays (676 packets in one session): S four times, then R, A, C, A again, round and round |

So the game takes a console portal's R answer as it is (no `ff ff ff` in front of the reply), activates
the portal and sets its light, the same commands as on Xbox 360; it gives up when A gets no answer.
